## Слой 1: B2B -- Брокер (покупатель продукта)

### Big Job (Большая работа брокера)

**"Построить прибыльный форекс-брокерский бизнес, привлекая и удерживая трейдеров, обеспечивая compliance, и масштабируясь на новые рынки, чтобы стабильно наращивать выручку от спредов, комиссий и свопов"**

### Core Job (Главная работа продукта для брокера)

**"Когда мне нужен клиентский портал для моей форекс-брокерской компании, я хочу современный, white-label, функционально полный trader room, который увеличивает удержание клиентов и объём депозитов, одновременно снижая расходы на поддержку, чтобы я мог наращивать выручку и конкурировать с крупными брокерами"**

- **Когда** (контекст): Брокер запускается или хочет улучшить существующий портал
- **Триггер**: Текущий trader room устарел / клиенты жалуются / конкуренты предлагают лучший UX
- **Мотивация**: Больше депозитов, меньше оттока, ниже расходы на саппорт
- **Ожидаемый результат**: Портал, который трейдеры любят, брокер легко администрирует

## Слой 2: B2C -- Трейдер (конечный пользователь)

### Big Job (Большая работа трейдера)

**"Зарабатывать на финансовых рынках через торговлю forex/CFD, управляя рисками и дисциплиной, чтобы обеспечить финансовый рост и независимость"**

### Core Job (Главная работа продукта для трейдера)

**"Когда я управляю своей торговой деятельностью у моего брокера, я хочу гладкий, интуитивный личный кабинет, где я могу пополнять счёт, выводить средства, управлять аккаунтами, отслеживать результаты и решать административные вопросы легко, чтобы я мог сосредоточиться на торговле, а не бороться с неудобным порталом"**

- **Когда** (контекст): Трейдер зарегистрировался у брокера или уже торгует
- **Триггер**: Нужно пополнить, вывести, проверить статус, загрузить документ, открыть новый счёт
- **Мотивация**: Минимум трения, максимум контроля, быстрое решение задач
- **Ожидаемый результат**: Все нетрадинговые задачи решаются за секунды, без обращения в поддержку

## Связь между слоями: B2C Jobs --> B2B Value

| B2C Small Job (трейдер) | Как решение создаёт B2B-ценность для брокера |
|--------------------------|----------------------------------------------|
| T-SJ1: Онбординг | Быстрый онбординг --> выше конверсия в FTD (+35% с 20-сек KYC) |
| T-SJ2: Депозит | Простой депозит --> больше deposit volume --> больше revenue |
| T-SJ4: Вывод | Прозрачный вывод --> trust --> меньше chargebacks и жалоб |
| T-SJ5: Аналитика | Встроенная аналитика --> трейдер не уходит на MyFXBook --> retention |
| T-SJ7: Поддержка | Self-service --> -40-60% тикетов --> снижение support costs |
| T-SJ8: Copy Trading | Social trading --> 61-74% retention, daily logins |

## Critical Job Sequence (B2C -- путь трейдера)

```
[1] Увидеть рекламу/рекомендацию брокера
     |
     v
[2] Зайти на сайт брокера --> перейти к регистрации
     |
     v
[3] Заполнить форму регистрации (T-MJ1.1-1.2)
     |         |
     |   [ОТТОК 25-40%] -- "Слишком много полей / KYC сразу"
     v
[4] Пройти KYC (T-MJ1.3-1.6)
     |         |
     |   [ОТТОК 15-30%] -- "Не хочу загружать документы прямо сейчас"
     v
[5] Открыть торговый счёт (T-MJ1.7-1.8)
     |
     v
[6] Сделать первый депозит (T-SJ2) <--- AHA-МОМЕНТ ДЛЯ БРОКЕРА
     |         |
     |   [ОТТОК 40-60%] -- "Нет моего платёжного метода / страшно"
     v
[7] Начать торговлю (уходит в MT4/MT5/cTrader)
     |
     v
[8] Вернуться для пополнения / вывода / анализа (T-SJ2-5)
     |
     v
[9] СТАТЬ ПОСТОЯННЫМ ПОЛЬЗОВАТЕЛЕМ --> retention + LTV
```

Каждая точка оттока -- это возможность для trader room улучшить конверсию брокера.
