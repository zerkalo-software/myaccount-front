## 1. Прямые B2B-конкуренты: анализ через AJTBD-линзу

### 1.1 B2Core (B2Broker)

**Позиция**: Крупнейший по клиентской базе -- 100+ брокеров, 1.5M+ активных трейдеров, $800M+ депозитов/год.

| Параметр | Значение |
|----------|----------|
| **B2B Jobs** | **85%** -- почти все задачи брокера |
| **B2C Jobs** | **55%** -- базовый кабинет, без глубокой аналитики |
| **Pricing** | Standard $1K, Advanced $1.5K, Enterprise $2.5K/мес. Setup $2.5K |
| **Стек** | Golang-based микросервисы, web + mobile |
| **Интеграции** | MT4, MT5, cTrader, DXtrade, B2Trader (собственный) |

**Сильные стороны**: Полная экосистема (CRM + TR + Back Office + IB + Liquidity). Golang-архитектура с 10-15x ускорением (2025). IB real-time, 200+ PSP, крипто-поддержка.

**Слабости**: Монолит -- всё или ничего. Одинаковый UI у 100+ клиентов. Миграция болезненна. B2C-опыт базовый, интерфейс перегружен.

### 1.2 Leverate (LXCRM + Sirix)

**Позиция**: Лидер рынка -- 19.6% доля, 20+ лет. End-to-end решение.

| Параметр | Значение |
|----------|----------|
| **B2B Jobs** | **90%** -- наиболее полное решение |
| **B2C Jobs** | **65%** -- Sirix v5 с social trading и prop |
| **Pricing** | Не публичный. Setup $10K-$50K. Месяц $1K-$3K+ (custom) |
| **Стек** | Sirix v5 (проприетарный), LXCRM |
| **Интеграции** | MT4, MT5, Sirix, VOIP, WhatsApp |

**Сильные стороны**: Sirix v5 с prop trading и social hub. AI-ассистент в CRM. VOIP/WhatsApp интеграция. Turnkey за 4-8 недель.

**Слабости**: Премиальная цена. Vendor lock-in на Sirix. Legacy под капотом. "Всё или ничего".

### 1.3 Match-Trader (Match-Trade Technologies)

**Позиция**: Быстрорастущий -- 160+ брокеров/проп-фирм, 1.8M трейдеров.

| Параметр | Значение |
|----------|----------|
| **B2B Jobs** | **75%** -- хорошо, но без глубокого CRM |
| **B2C Jobs** | **70%** -- TradingView charts, social trading, хороший UX |
| **Pricing** | White Label от $2.5K/мес. Server от $5K/мес. Прозрачная модель |
| **Стек** | Собственная платформа + TradingView, AWS/Azure включён |
| **Интеграции** | Match-Trader + MT5 (Prop CRM), TradingView |

**Сильные стороны**: Прозрачные цены (редкость). Встроенные TradingView charts. Prop CRM + MT5. Модульность. Независимость от MetaQuotes.

**Слабости**: Нет MT4. Нет cTrader. CRM незрелый. Привязка к своей платформе. Фокус смещается на prop.

| Параметр | Значение |

**Сильные стороны**: Деплой за 2-4 недели. 800+ инструментов, 200+ PSP. Modern UI/UX. 99.5% SLA.

**Слабости**: Setup $20K-$42K. Нет MT4/MT5. Закрытая экосистема. Binary options репутация. Нет API.

### 1.5 UpTrader

| **Pricing** | Self-served от ~$500/мес. Enterprise: custom. Модульная модель |
| **Стек** | Не раскрыт |

**Сильные стороны**: Доступная цена. Модульность. UpTrader Invest (Copy + PAMM + MAM). Prop на всех тарифах. Мульти-валютные кошельки.

**Слабости**: Незрелый продукт. Непрозрачный стек. Ограниченная документация. Риски масштабирования.

| Параметр | Значение |

**Сильные стороны**: Widget-based API-first -- самый модульный. CMS для брокера. 5 торговых платформ. AI KYC (30-60 сек). Brokeree Social Trading + PAMM. Prop модуль.

**Слабости**: Непубличные цены. Кипр-база. Нет своей платформы. UI менее современный. Малая узнаваемость.

## 3. AJTBD Gap Analysis: недообслуженные задачи

### 3.1 Задачи, которые НЕ РЕШАЕТ ни один конкурент

| # | Задача | Слой | Проблема |
|---|--------|------|----------|
| 1 | **B2C-аналитика уровня MyFXBook/TradesViz** | B2C | Трейдеры уходят на внешние сервисы -- ни один TR не даёт даже базовых метрик |
| 2 | **Кастомизация UI без кода** | B2B | Только Syntellicore CMS (ограниченный). Брокеры хотят менять UI сами |
| 3 | **Единый TR для MT4+MT5+cTrader+DTS** | B2B/B2C | Обычно 2-3 платформы максимум. Все 4 -- ни у кого |
| 4 | **Поведенческая аналитика** | B2C | Overtrading, revenge trading, эмоциональные паттерны -- нигде нет |
| 5 | **Prop trading на любой платформе** | B2B | Prop есть, но привязан к конкретной платформе |
| 6 | **AI-инсайты для трейдеров** | B2C | 68% брокеров хотят AI, но AI только в KYC и чат-ботах |
| 7 | **Real-time статус выводов** | B2C | #3 жалоба трейдеров, push-уведомления нигде нет |
| 8 | **Экономический календарь** | B2C | ForexFactory: 26.8M визитов. Только UpTrader (базовый) |
| 9 | **Модульная компонентная архитектура** | B2B | Syntellicore стремится, но на legacy. Остальные -- монолиты |
| 10 | **Gamification онбординга** | B2C | Ни один TR не использует gamification для первого депозита |

### 3.2 Blue Ocean возможности myaccount-front

**#1: B2C-аналитика внутри trader room** -- MyFXBook (7.2M визитов/мес) и TradesViz (600+ статистик) доказывают спрос. Ни один TR не даёт даже 10% этого. Базовые метрики (win rate, drawdown, P&L calendar, equity curve) = мгновенная дифференциация. Аргумент: "ваши трейдеры перестанут уходить на MyFXBook".

**#2: Современный стек + мульти-платформа** -- Next.js 16 + React 19: ни один конкурент не на современном JS-фреймворке. MT4+MT5+cTrader+DTS v2 через xCritical -- самый широкий охват. Компонентная архитектура = модульность на уровне дизайна.

**#3: Компонентная кастомизация** -- Собирать уникальные кабинеты из готовых блоков (атомы/молекулы/организмы). Syntellicore стремится к этому (widget-based), но на legacy.

**#4: AI-first** -- 68% брокеров хотят AI. Ни один TR не даёт AI-инсайты трейдерам. Возможность: персональные рекомендации, аномалии, прогноз drawdown.

## 6. Ключевые выводы

1. **Рынок фрагментирован** -- даже Leverate (19.6%) далёк от доминирования. Нет решения, закрывающего все задачи.

2. **B2C-аналитика -- главный blue ocean**. Ни один конкурент не даёт аналитику уровня MyFXBook. Самый явный gap.

3. **Современный стек -- реальное преимущество**. Все конкуренты на проприетарных или legacy-стеках. Next.js 16 -- уникальная позиция.

4. **Мультиплатформенность через xCritical** -- MT4+MT5+cTrader+DTS v2 в одном кабинете есть только у нас.

5. **Mid-tier ($1.5K-$5K) -- целевое поле битвы**. Leverate дорог, UpTrader рискован, B2Core стандартен. Окно открыто.

6. **Prop trading** -- Match-Trader лидирует, но привязан к своей платформе. Prop на MT4/MT5 через xCritical -- незанятая ниша.

7. **AI -- fast follower**. 68% хотят AI, но пока только KYC и чат-боты. AI-аналитика для трейдеров -- незанятая территория.

8. **Brokeree -- партнёр, не конкурент**. Интеграция xCritical+Brokeree уже есть. Social Trading и PAMM через партнёрство.
